Adult echocardiography · Aortic root reference values

About aoroot

One adult aortic root or ascending aorta measurement, scored against several published echocardiographic references side by side, so the differences between references are visible rather than hidden behind a single number.

← Calculator · How to cite

What it does

Enter sex, age, height and (optionally) weight, then any of the four standard sites: annulus, sinuses of Valsalva, sinotubular junction and ascending aorta. Each reference that covers that site and measurement convention returns its predicted value, normal range, z-score and percent of predicted. There is no default or "headline" reference: the references disagree, sometimes by more than a z of 1, and the comparison is the point.

Charts show the same patient as a share of what each reference expects, and how each reference's prediction changes with height or age. Risk and surgical thresholds indexed to height (Desai 2026) are shown for context, alongside a cardiac MRI upper limit of normal (Tavolinejad 2025).

How the references were chosen

no range, no model
  • A normal range is required. A reference is included only if the paper gives a spread (an SD, SEE or published limit). Mean-only equations are left out, because a predicted value with no range invites misreading. Where only a percentile limit is printed, the SD is backed out from it if a normal distribution looks reasonable, and that check is written in the reference's notes.
  • Body size, not size alone. Sex-only absolute values are not shown; every model adjusts for body size, age or both.
  • Race and ethnicity are never an input. Each study's population is described on the references page in the paper's own words. Where a paper publishes separate equations by population, you can choose among them as a view option.
  • Every number is traceable. Each coefficient, SD and limit is stored with the table or page it came from, checked by hand against the publication, and covered by tests that reproduce values printed in the paper wherever the paper prints any.

See References for every equation, population and note, and Tests to run the checks yourself.

What it is not

  • Adults only. Pediatric aortic z-scores use different references and are well served elsewhere.
  • An educational and reference tool, not a medical device. A z-score is one input to clinical judgment, not a diagnosis; check important results against the original publications.

Privacy

All calculation runs in your browser. Nothing you enter is stored or sent to a server; the values live only in the page's link, so sharing a link shares the values. Don't enter names or other identifiers.
