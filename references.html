Reading this page

  • Each reference lists its population, every model the calculator uses (equation, spread, valid range) and the table or page each number was taken from.
  • Status: reviewed means every model was checked by hand against the publication. Numbers are shown as stored, so trailing zeros drop (0.010 shows as 0.01).
  • Tests run in your browser as the page loads: paper tests reproduce values printed in the publication; independent ones match another implementation; arithmetic ones are hand calculations.
