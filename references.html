How to review a reference

tick as you go; your ticks stay in this browser
  1. Open the paper beside this page. For each model, compare the equation, SD and limits with the cited table or page, then tick it.
  2. Numbers here are shown as stored, so trailing zeros drop (0.010 shows as 0.01). "Registry file as entered" shows the exact text.
  3. Check the tests: paper tests reproduce values printed in the publication; independent ones match another implementation; arithmetic ones are hand calculations.
  4. Add any comments, then "Copy review summary" and send it to be recorded. The reference's draft flag is removed once its status is set to reviewed.
